# Dictate

本机流式听写：按住**右 Option 说中文**，按住 **Fn 说 English**。刘海 HUD 会随麦克风音量即时发光，并用灰色草稿实时出字；松开后把 FINAL 一次性送回开始听写时的输入框，或只复制到剪贴板。Esc 取消，不提交。菜单栏也可点「开始 / 停止听写」。

识别使用系统 **SpeechAnalyzer**（macOS 26+），音频不出本机。PARTIAL 只显示在浮层，只有 FINAL 可以进入提交文本；松手会等待结果流排空，不会拿临时稿凑数。系统本地翻译默认开启，正常提交为「原文 + 译文」。

## 用法

```bash
./scripts/run.sh
```

第一次：

1. 允许麦克风
2. 系统设置 → 隐私与安全性 → **辅助功能** 和 **输入监控**，打开 Dictate
3. 点任意输入框，按住**右 Option**约 0.16 秒后说中文，或按住 **Fn** 说英文，松开插入。短按和快捷键组合不会触发听写。也可以点菜单栏麦克风 →「开始 / 停止听写」

菜单栏麦克风图标可打开权限设置。语言默认 `zh-CN`（中文里夹英文词一般能吃）。

中文和英文识别器会同时预热；热键不需要先打开菜单切换。菜单栏可直接切换：

- **识别语言 → 中文（可夹英文） / English**：设置菜单栏「开始 / 停止听写」使用的语言；设置会保存。右 Option / Fn 始终分别对应中文 / English。
- **完成方式 → 插入原输入框 / 只复制到剪贴板**：默认为插入；复制模式不会模拟 `⌘V`。
- **复制上次听写结果**：重新把本次运行中最近一段成功听写的完整结果写入剪贴板。
- **附带本地翻译（原文 + 译文）**：默认开启；中文自动译成英文，英文自动译成中文。复制模式下会复制原文和译文。
- **打开翻译语言设置**：安装或管理 Apple 本地翻译语言包。

```bash
./scripts/bundle-app.sh          # Release 包
open Dictate.app --args --locale en-US
open Dictate.app --args --no-translate
open Dictate.app --args --copy
open Dictate.app --args --preview-hud   # 开发/主题预览
```

松手后最多等待翻译 2 秒。已经完成的译文会与原文一起提交；翻译超时、失败或语言包未安装时会明确提示，并安全回退为原文，不会卡住自动插入。

## 提交安全

- 开始听写时记录前台进程和 Accessibility 焦点元素；松手时焦点不一致就不写入，只把文字留在剪贴板。
- 支持的输入框优先通过 Accessibility 一次性写入，不碰剪贴板；不支持时才保存剪贴板并尝试一次 `⌘V`。
- 选择“只复制到剪贴板”时，每段听写只写一次剪贴板，不修改当前输入框；该设置会保存。
- 安全输入框不自动插入，也不把听写文本写入剪贴板。
- 自动粘贴后按完整 item/type 恢复原剪贴板；如果期间有其他程序改过剪贴板，则不覆盖它的新内容。
- `⌘V` 属于一次经过目标校验的粘贴尝试，第三方应用是否真正接收仍由该应用决定。

## 开发

```bash
swift test --package-path .
```

核心状态机在 `DictateCore`：PARTIAL 只覆盖临时稿，FINAL 才进插入文本。HUD 的音量动效直接来自麦克风缓冲，不等待识别结果，因此开口后会先即时响应。

当前打包脚本生成本机使用的 ad-hoc 签名应用；对外分发仍需 Developer ID、hardened runtime 和 notarization。
